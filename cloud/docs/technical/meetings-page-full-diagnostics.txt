5) PROXY LAYER (lib/api-gateway.ts) - FULL DETAILS
============================================================
Base URL resolution order:
1. API_GATEWAY_URL
2. SERVER_API_GATEWAY_URL
3. NEXT_PUBLIC_API_GATEWAY_URL
4. NEXT_PUBLIC_API_URL
5. default http://localhost:4000

Timeout resolution:
- per-call timeoutMs if provided
- else env API_GATEWAY_PROXY_TIMEOUT_MS
- else fallback 30000ms

On network failure to gateway:
- returns 502 or 504
- payload contains:
  - error
  - code
  - detail
  - upstream { baseUrl, url }
  - hint

On non-JSON upstream response:
- wraps error with body snippet + hint

10) 502 FAILURE MODES FOR /start
============================================================
A) Next proxy cannot reach gateway
- Symptom: 502 with hint about API gateway URL/running service.
- Cause: gateway process down/wrong URL.

B) Gateway returns 502 from Google Meet creation
- Symptom: payload code often starts with GOOGLE_MEET_...
- Common causes:
  - service account not shared on calendar
  - calendar id wrong/not found
  - invalid service-account key/json
  - Google API rejects conference creation

C) Timeout path
- Symptom: 504/502 with timeout hint.
- Cause: long-running gateway call/network latency.
