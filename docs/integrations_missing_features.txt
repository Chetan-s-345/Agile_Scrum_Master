AI Sprint Manager — Integration Gaps Checklist (Jira + GitHub)
Generated: 2026-03-23

================================================================================
JIRA — Missing / Partial Backend Features
================================================================================
1) Webhook verification is not per prompt
   - Prompt: verify X-Atlassian-Token or compare webhook secret
   - Current: verifies x-jira-webhook-secret only when JIRA_WEBHOOK_SECRET is set
   - Missing: optional X-Atlassian-Token validation strategy (Jira Cloud often expects X-Atlassian-Token: no-check for some callbacks)

2) Jira webhook event handling is best-effort (not full spec)
   - Missing: parse changelog for assignee/status/story_points changes and apply to tasks
   - Missing: jira:issue_created mapping to backlog vs tasks based on sprint/issue context
   - Missing: sprint_completed “trigger sprint completion flow” (calls existing sprint completion controller/service)

3) Jira outbound sync is not wired into task lifecycle
   - JiraService has: createIssue, updateAssignee, updateStatus, moveToSprint
   - Missing: task routes calling these when:
     - a task is created (createIssue)
     - status changes (updateStatus)
     - assignee changes (updateAssignee)
     - delay predictor moves task (moveToSprint)

4) Data model mismatch vs prompt
   - Prompt mentions tasks.jira_synced=true; current schema has no tasks.jira_synced column
   - Prompt maps story_points -> ai_estimated_points for backlog; current sync writes story_points

5) Jira status endpoint fields not complete
   - Prompt expects totalSynced (or similar aggregation)
   - Current returns connected/baseUrl/projectKey/lastSyncAt/syncStatus/syncError/fieldMappings

JIRA — Missing UI Features
================================================================================
1) No Jira webhook UI setup guidance
   - Missing: show webhook callback URL + required headers/secrets
   - Missing: show last webhook event + processing failures

2) No visibility for sync log details
   - Missing: show latest jira_sync_log records, errors, counts

3) No UI to trigger/schedule incremental sync per project/board
   - Only “Sync now” exists

================================================================================
GITHUB — Missing / Partial Backend Features
================================================================================
1) GitHub organization creation is NOT feasible via API (PAT)
   - Must be created in GitHub UI
   - Current implementation can create a repo in an existing org when createIfMissing=true

2) Webhook registration prerequisites
   - Requires PUBLIC_API_GATEWAY_URL (publicly reachable HTTPS) to register a webhook
   - If PUBLIC_API_GATEWAY_URL is missing, connect still works but webhook registration is skipped

3) Automatic “task progress update” is partial
   - We store github_events and can update task status to in_review/done
   - Missing: a first-class task progress field (none in schema), and rules for progress calculation

4) Linking GitHub activity to tasks is limited
   - Current heuristic: parse Jira-style issue key (ABC-123) from commit message / branch / PR title
   - Missing: support for internal task IDs, custom prefixes, or GitHub issue numbers

5) PR review timing and metrics
   - We estimate review/merge hours and update avg_pr_review_hours (simple smoothing)
   - Missing: more accurate aggregation (per reviewer, per project, per sprint)

================================================================================
GITHUB — Missing UI Features
================================================================================
1) Repo discovery/list UI
   - Missing: list all repos accessible to the token
   - Current UI: connect a single org+repo by name and show connected repo

2) Webhook setup status UI
   - Missing: show webhook callback URL + last delivery status/recent failures

================================================================================
AUTOMATIC TASKS + SPRINT WORKING — Missing Features
================================================================================
1) Auto-create internal tasks from GitHub signals
   - Missing: create tasks/backlog items from GitHub Issues (opened/labeled) or PRs

2) Auto-sync sprint state from Jira/GitHub
   - Missing: consistent mapping from Jira sprint start/complete to local sprint start/complete flows

3) “Bidirectional” status sync is not complete
   - Inbound from Jira exists (sync + webhook best-effort)
   - Outbound to Jira exists in service but not wired into task routes

4) Background processing reliability
   - Missing: DLQ / retry policy and admin UI for failed webhook_events
